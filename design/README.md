# 시안

원본 캔버스(편집 가능): https://claude.ai/artifact/RiTGixbfaxk2kjFkGr5RFV

`mockups/`의 파일은 그 캔버스의 원본 소스입니다. Claude 디자인 캔버스 형식(`.dc.html`, `<x-dc>` 템플릿)이라 브라우저에서 바로 열리지 않습니다. 레이아웃, 색, 문구, 간격을 참고하는 용도로 읽고, 실제 화면은 `web/`에 일반 HTML로 새로 만듭니다.

| 파일 | 화면 | 기획서 |
| --- | --- | --- |
| Main.dc.html | 나눔 (첫 화면): 나누기 입력 줄, 다섯 연결 띠, 생각 카드 | 3-1, 3-3 |
| Thread.dc.html | 함께 다듬기 (상세): 생각 전문, 갈라진 가지 한 줄, 이어 쓰기 목록과 입력줄 | 3-1, 3-2 |
| Connect.dc.html | 연결 (두 번째 탭, 2단계): 자녀를 가운데 둔 다섯 연결 지도 | 3-3 |
| Compose.dc.html | 생각 나누기 (입력) | 3-1, 3-5 |

시안에 아직 없는 것(기획서 기준으로 넣을 것): 처음 안내 카드, 지난번 이후 새로, 오늘의 질문 카드, 별칭 칩, 연결별 생각 꺼내기 문장, 글자 크기 버튼, "함께"가 기본 선택된 연결. 글꼴은 시안이 Noto Sans KR이지만 기획서대로 Pretendard를 씁니다. 색과 간격은 기획서 8장이 기준입니다.
