# 1단계 점검표

기획서 7장 1단계 완료 기준. 2026-10-10 서버·화면 배포, 실제 시트 세팅(setupAll) 끝.

- 페이지: https://tk-korea.github.io/five-people-garden/
- 관리: https://tk-korea.github.io/five-people-garden/#/admin

## 시작 전 (TK)

- [ ] 관리 화면에서 **참여 코드**를 바꾸고, 나온 공지 문구(`#c=` 링크 포함)를 복사해 둔다.
- [ ] 관리 화면에서 **관리 코드**를 바꾸고 안전한 곳에 적는다. setupAll 로그에 찍힌 처음 코드는 버린다.
- [ ] 시트의 0단계 탭(`stage0_text`, `stage0_text2`, `stage0_log`)을 지운다(선택).

## 완료 기준

| # | 확인 | 방법 | 결과 |
| --- | --- | --- | --- |
| 1 | 세 사람이 각자 휴대폰으로 생각을 나누고 서로 이어 쓴 뒤, 새로고침해도 그대로 보인다 | `#c=` 링크를 세 사람에게 보내 카톡에서 연다 | |
| 2 | 연로한 성도 한 분이 큰 글씨로 `#c=` 링크를 열어 도움 없이 생각 하나를 나눈다 | 휴대폰 글꼴을 크게, 화면 위 "가"로 150% | |
| 3 | 코드가 없는 기기에서는 보낼 때 코드를 묻고, 쓴 글은 사라지지 않는다 | 링크 없이 주소만으로 열어 나누기 | |
| 4 | 전화번호를 넣으면 경고가 뜬다 | 제목에 010-0000-0000 | |
| 5 | 같은 글을 두 번 눌러도 한 번만 저장된다 | 나누기를 빠르게 두 번 | |
| 6 | 실명이 든 시험 글을 고치고 지운 뒤 시트와 log에 이름이 남지 않는다 | 관리 화면 "개인정보 지우기" 뒤 시트의 ideas·log 탭 확인 | |
| 7 | 관리 화면에서 두 코드를 바꾼 뒤 처음 코드는 무효다 | 시작 전 단계 뒤, 처음 코드로 나누기 시도 | |
| 8 | 백업과 guard 정리 트리거가 실제로 한 번 돈다 | 월요일 새벽 3시 뒤 드라이브 "한 아이 곁에 다섯 사람 백업" 폴더, Apps Script "실행" 기록 | |
| 9 | app-qa-test 스킬 점검을 통과한다 | 1~7 뒤 Claude에게 요청 | |

## 0단계에서 넘어온 것

- [ ] iOS 카톡에서 열기, 나누기, 이어 쓰기, 키보드와 입력줄, 큰 글씨
- [ ] Android 카톡에서 링크를 닫았다 다시 열어도 코드와 내 글이 남는지(0단계 요약과 직접 확인이 달랐음)
- [ ] Android 시스템 글꼴을 가장 크게 했을 때 화면

## 시험 글 정리

시험이 끝나면 시험 글은 지우거나(내 글 → 지우기, 또는 관리 화면 숨기기) 그대로 첫 씨앗의 이어 쓰기로 남긴다(기획서 5-1 첫 씨앗).
