# 배경

## 출발점

"다음세대를 일으키기 위해 아이 한 명이 다섯 명의 의미 있는 관계를 맺어야 한다"는 한 형제님의 관찰. 같은 숫자를 쓴 연구로 풀러 청소년 연구소의 Sticky Faith(아이 한 명에게 믿는 어른 다섯 명)가 알려져 있으나, 워치만 니·위트니스 리 사역에서 나온 표현으로는 확인하지 못했다. 숫자는 관찰로 받고, 원칙은 성경과 사역의 관점으로 푼다.

다섯 연결(TK가 정함, 자녀를 가운데 둔 그림): 친구, 부모, 봉사, 다른 부모, 조부모.

## 관련 구절 (장절과 요지, 회복역 본문 문구는 확인 필요)

- 딤후 1:5 — 디모데의 믿음은 외할머니와 어머니 안에 먼저 있었다.
- 딤후 2:2 — 바울, 디모데, 신실한 사람들, 또 다른 사람들로 이어지는 네 세대.
- 살전 2:7, 11 — 양육하는 어머니처럼, 권면하는 아버지처럼.
- 시 145:4 — 한 세대가 다음 세대에게 주님의 일을 전한다.
- 요 21:15 — 내 어린양을 먹이라.
- 엡 4:16 — 몸은 각 마디의 공급과 각 지체의 기능으로 자란다.

## 처음 정리한 실제 방안 (첫 씨앗의 출처)

1. 관계 지도 그리기: 아이마다 부모 외에 이름을 알고 기도해 주는 성도가 몇 명인지 적어 본다.
2. 다섯 자리를 다양하게: 서로 다른 연결의 사람으로 채운다.
3. 식탁 열기: 한 달에 한 번 다른 가정의 아이를 집에 초대해 함께 먹고 찬송 한 곡.
4. 중고등부로 올라가기 전에 다리 놓기: 6학년이 올라가기 전에 중고등부 형제자매와 섬기는 성도를 미리 만나게 한다.
5. 이름으로 기도하기: 성도마다 아이 한두 명을 맡아 매주 이름을 불러 기도한다.

주의: 이 페이지는 배정 명단이 아니다. 다섯 연결은 생각을 분류하고 빈 곳을 보는 렌즈일 뿐이다.

## 용어

- 회복에서 쓰는 말을 따른다: "진급"이 아니라 **"중고등부로 올라가기"**.
- 공개 페이지에는 아이 이름 대신 "초등 고학년 아이", 쓴 사람은 "섬기는 형제" 같은 역할 별칭.

## 브레인스토밍 질문 (questions 탭 초기값)

1. 지금 우리 아이들 중 부모 말고 기억하는 어른이 거의 없는 아이는 몇 명쯤일까?
2. 아이가 집회를 떠나는 시점은 언제인가? (중고등부로 올라갈 때, 이사, 사춘기)
3. 성도들이 아이와 관계를 맺지 못하는 진짜 이유는 무엇인가? (시간, 어색함, 방법을 모름)
4. 이미 자연스럽게 잘 되고 있는 관계는 어디서 생겼는가?

## 진행 기록

- 기획서 작성 → 시안 5안 → 개념 전환("나누고, 저장하고, 서로 보며 키우기") → 추천 조합(나눔 피드 + 함께 다듬기 + 연결 탭 + 나누기 화면) 확정
- 프리셋 적용 → 1차(빠진 것) · 2차(장 사이 모순) · 3차(구현 계약, 별도 검토자) · 4차(실제 사용 흐름, 별도 검토자) 검토 반영
